# Firmware-specific notes:
# - Keep Live TV enabled. com.mediatek.wwtv.tvcenter also plays HDMI; disabling it breaks both.
# - Do not disable com.google.android.apps.tv.launcherx before CleanYourTV is installed and owns Home.
#   launcher/build-and-install disables the stock launcher after that; restore.sh needs launcherx as
#   its argument.
# - The remote's gear button sends keycode 83 (KEYCODE_NOTIFICATION, scancode 561). Only launcherx
#   handled it, so set settings_key_keycodes to [83] (config.xml or a theme) for the launcher's
#   Settings panel.
# - HomeKeyService, used for the gear button, can stop volume long-press from repeating on some TCL
#   Google TV builds: holding volume then steps once. Set key_filter=false to restore the repeat and
#   lose the remapped keys, or leave HomeKeyService off. See docs/TROUBLESHOOTING.md.
# - The saved Wi-Fi network survived disabling setupwraith here without forgetting and re-joining.
#   Check dumpsys wifi / the network owner on another unit before copying this step.
# - Switch the screensaver to ClockDream before disabling dreamx:
#   tools/tv.py 'settings put secure screensaver_components com.gathin.tvhome/.ClockDream'
#   (undo: tools/tv.py 'settings delete secure screensaver_components')
#
