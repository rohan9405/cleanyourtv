# ro.product.model=V560V2_CPFC1_0  ro.product.device=EBONY_V560
# ro.build.version.release=9  ro.build.version.sdk=28
# ro.build.display.id=PPR1.180610.011 release-keys  ro.product.manufacturer=TPV
# About 2 GB RAM, 32 GB storage, no GMS (no com.google.* on this unit).
# Hisilicon platform: com.hisilicon.* holds the chip vendor's own apps.
#
# This is NOT one of the other Philips lists in this repo. Those are the TP Vision
# org.droidtv platform (examples/philips-50pus8517, philips-tpm191e, philips-55pus7503)
# or the TPV PH0M_EA_T32 board (examples/philips-50pud7406). This set is a China-market
# set: three package families sit side by side -- tv.fun.* (BestV / the 百视通 platform),
# com.newtv.* + tv.newtv.loginservice (the NewTV IPTV platform) and com.tpv.* (the board).
# There is no org.droidtv.xtv here, so the 50PUS8517 quirk about eum and aurora does not
# apply the same way -- but eum still has to be left alone, see below.
#
# Stock launcher: com.bestv.ott (BestV / 百视通), which is NOT in the repo's
# KNOWN_STOCK_LAUNCHERS list. Pass it explicitly when the launcher takes over:
#   STOCK_LAUNCHER=com.bestv.ott TV_HOST=<tv ip> launcher/build-and-install.sh
#
# Live TV / inputs: com.tpv.tvinput, the only TvInputService on this set
# (tuner, HDMI, VGA, composite, component, SCART).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/philips-50puf7099-t3/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/philips-50puf7099-t3/debloat.txt com.bestv.ott
# Everything is DISABLED, not uninstalled. Comment out anything you want to keep.
#
# ADB: ro.adb.secure=0, so port 5555 accepts any device on the network with no prompt.
# Turn USB debugging and network ADB off again when you are done.
#
# Tested on this unit, 2026-10-26: the whole list below applied, then the launcher
# install, then a reboot. Nothing came back, no crash, the input menu still lists
# HDMI 1, HDMI 2, HDMI 3 and composite. Not yet checked over several days, and the
# real remote keys have not been tried (only injected keys, deviceId=-1).
#
# QUIRKS ON THIS FIRMWARE:
#
# 1. The three upgraders all hold INSTALL_PACKAGES. tv.fun.tvupgrade is the
#    installerPackageName of com.bestv.ott itself, so while it lives it can put the
#    BestV launcher back and wipe this list. Disabling it gives up system OTA.
# 2. Screensaver. screensaver_components shipped pointing at
#    com.google.android.deskclock/com.android.deskclock.Screensaver, but that package
#    is not installed and pm query-services -a android.service.dreams.DreamService
#    answers "No services found": this set had no screensaver at all. After the
#    launcher install, point it at the launcher's own clock:
#      settings put secure screensaver_components com.gathin.tvhome/.ClockDream
#      settings put secure screensaver_default_component com.gathin.tvhome/.ClockDream
#    There is no backdrop package here, so the 50PUD7406 screensaver quirk does not apply.
# 3. org.droidtv.usagelogger asks for android.permission.TV_INPUT_HARDWARE, so
#    tools/disable.sh skips it by default. It is a false positive on this set:
#    pm query-services --components -a android.media.tv.TvInputService lists only
#    com.tpv.tvinput's six services, usagelogger is not among them. Disabling it
#    needs TVINPUT_ALLOW=1. Same as examples/cecotec-shandao.
# 4. The screen is 60 Hz 4K on a 2 GB set, so lowmemorykiller is active at idle.
#    Every background service removed is a net gain.
# 5. default_input_method is com.android.inputmethod.pinyin/.PinyinIME, which is
#    installed -- not the Xiaomi quirk where it points at a missing com.baidu.input.
