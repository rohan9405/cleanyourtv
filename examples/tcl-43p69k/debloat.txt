# Known quirks on this firmware:
# - The saved Wi-Fi network from first setup belongs to setupwraith (dumpsys wifi: cname=...setupwraith).
#   Forget and re-join it in Settings before setupwraith is disabled, or the TV drops off Wi-Fi and ADB.
# - TclAppBoot blocks the launcher until it has APP_AUTO_START (appops set + appops write-settings).
# - Any bound key-filtering helper costs held-volume repeat here, as on the G09 (docs/devices/
#   tcl-55p71b-g09-key-repeat.md); the launcher's key_filter false keeps the repeat, but its app_keys then
#   do nothing.
# - The remote's Settings (gear) key is KEYCODE_NOTIFICATION (83); app keys are Netflix 4062, Prime Video
#   4099, YouTube 4065, Disney+ 4141, TCL Channel 4020.
