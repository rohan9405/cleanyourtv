# TCL 40" Google TV, India (device G13, product G13_2K_GB, MediaTek mt5867, ~1 GB RAM)

# security patch 2026-06-01. ro.adb.secure=1.
# Retail listing: TCL 101 cm (40 inch) 2K QHD Google TV, V5C series.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g13-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g13-google-tv/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / tuner: com.mediatek.wwtv.tvcenter.
# Keep com.tcl.suspension (source/standby), com.mediatek.tv.service and com.mediatek.tvinput (HDMI/tuner).
#
# Not done here: no custom launcher. See README.md in this folder — on this exact board the stock
# launcher is force-relaunched by a hardcoded platform service (BootModeAppToForeground, from the
# com.android.libraries.tv.tvsystem shared library) that bypasses RoleManager's HOME role entirely,
# unlike the G08 board (also Google TV 14, same debloat approach) where the launcher swap works.
#
# All 7 packages below were disabled and reboot-checked (pm list packages -d persisted, TV booted
# normally, Home resolved to the stock launcher as expected) on 23 October 2026.
