# France, Wi-Fi only. Same product and build as examples/tcl-65c735; this list started from that one.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-65c935/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-65c935/debloat.txt com.google.android.apps.tv.launcherx
# Theme:   TV_HOST=<tv ip> tools/theme.sh examples/tcl-65c935   (config.json: dock, Live TV, remote keys)

# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Applied in five batches with a screenshot between each: Home, the TCL Quick panel (Input key), HDMI,
# Wi-Fi, Play Store and YouTube worked after every batch and after a reboot. One evening of use.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI: com.tcl.tv + com.tcl.tvinput.
# Connection: USB debugging alone opens port 5555 on Wi-Fi; no Wireless debugging needed.
#
# Comes back on by itself, re-enabled by com.tcl.ttvs (kept here: on AR2101 it hosts the system updater):
# com.tcl.esticker within minutes, com.tcl.usercenter, com.tcl.notereminder and com.tcl.smartalexa at
# every boot. They stay in the list so restore records them; tools/check.py reports these four as drift.
#
# setupwraith (batch 5) owned TWO saved Wi-Fi networks on this unit: the one in use and an old SSID from
# a previous ISP. Forgetting and re-joining the current one in Settings moved it to com.android.tv.settings,
# but disable.sh still refused setupwraith because of the old one, which Settings offered no way to forget.
# `cmd wifi list-networks` showed its id and `cmd wifi forget-network <id>` removed it. Disabling setupwraith
# then survived a reboot, like the 65C735 and unlike examples/tcl-g05-google-tv (same AR2101 build id).
#
# Remote (keycodes read from logcat `TclPhoneWindowManager: handleKeyBeforeQueueing, key = N`):
# gear 4077, Input 178 (opens the TCL Quick panel without any helper), Netflix 4062, YouTube 4065,
# Prime Video 4099. config.json maps them for HomeKeyService; holding Volume+ still auto-repeats with
# the helper bound (repeatCount climbed normally), so key_filter costs nothing on this build.
# After tools/theme.sh restarted Home, HomeKeyService was left enabled but UNBOUND (dumpsys accessibility:
# "Bound services:{}"), so the gear did nothing until the list was cleared and rewritten with
# accessibility_enabled toggled off and on, plus `appops set com.gathin.tvhome AUTO_START allow; appops
# write-settings`. restore_key_services is on in config.json so Home repairs it after a force stop.
#
# `tools/tv.py 'reboot'` never returns on this set (the connection drops mid-call); run it in the
# background or with a timeout.
#
# Kept by choice: com.tcl.ttvs (updater), Google Assistant (com.google.android.katniss,
# com.google.android.tv.assistant), Chromecast (com.google.android.apps.mediashell), the USB media
