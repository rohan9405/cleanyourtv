# Wi-Fi ownership gotcha on Google TV 14:
# Before disabling com.google.android.tungsten.setupwraith, verify Wi-Fi owner:
#   dumpsys wifi | grep -o 'cname=[^ ]*' | sort -u
# If it outputs 'cname=com.google.android.tungsten.setupwraith', the initial setup wizard owns the Wi-Fi
# credentials: disabling it immediately drops Wi-Fi and disconnects ADB!
# FIX: Go to TV Settings > Network & Internet > select Wi-Fi > Forget network > reconnect.
# Re-check dumpsys wifi until cname=android.uid.system:1000 appears. Then it is safe to disable setupwraith.
