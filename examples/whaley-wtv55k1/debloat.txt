# Whaley WTV55K1 (MStar helios), China, Android 5.0.2 (API 21), build 2018-12-07
# Chinese Whaley (Micro Whale) firmware. Stock home: com.helios.launcher (keep enabled).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/whaley-wtv55k1/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/whaley-wtv55k1/debloat.txt
# Everything is HIDDEN, not uninstalled.
#
# IMPORTANT - this firmware refuses `pm disable-user` from the adb shell:
#   java.lang.SecurityException: Permission Denial: attempt to change component state
# The working channel on Whaley is `pm hide <pkg>` (reversible with `pm unhide`).
# Hidden state survives reboot. tools/disable.sh may need a Whaley-specific branch
# for this: swap disable-user for hide on packages that fail the SecurityException.
#
# Telemetry evidence (AdGuard Home query log, live network, 2026-10-24):
# the firmware queries *.aginomoto.com (ad., wlslog., u., member., appstore., kids.,
# vod., passport., parse., parse2., parse3.), scs.openspeech.cn and ic.tv.aliyun.com
# at 30+ DNS queries/hour straight from boot. Hiding the packages below stopped all
# of it (verified: zero queries after factory reset + reboot with packages hidden).
#
# MUST STAY ENABLED:
#   com.helios.launcher (stock home)
#   com.helios.setting, com.helios.mediaplayer, com.helios.vod (launcher deps)
#   com.iflytek.xiri, com.iflytek.xiri.recorder.svc, com.helios.voice,
#   com.helios.heliosvoice (remote voice key chain)
#   com.yunos.* / payment services (leave alone)
#   com.mstar.* (board services)
#
# Quirks, all checked on the TV:
# - `pm disable-user --user 0` refused for every package (SecurityException, shell uid)
# - `pm trim-caches` needs a suffix: "1G" works, a bare number fails "Invalid suffix"
# - overwrite-install of a RUNNING app is cancelled by the ROM: am force-stop first
# - shell cannot read /data/app or other packages' data dirs (no per-app size audit)
# - 5555 is NOT port-forwarded to the WAN on a stock iKuai router (checked from an
#   external vantage point); LAN-only exposure as usual
